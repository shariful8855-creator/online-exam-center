অনলাইন পরীক্ষা কেন্দ্র — লিখিত/ছোট প্রশ্ন সংস্করণ

শিক্ষার্থী প্রতিটি প্রশ্নের নিচে নিজের উত্তর টাইপ করবে। জমা দিলে মোট প্রশ্ন, উত্তর লেখা প্রশ্ন, ফাঁকা প্রশ্ন, নিজের লেখা উত্তর এবং সঠিক উত্তর/ব্যাখ্যা দেখবে। এটি উত্তর-লেখার পরিসংখ্যান; স্বয়ংক্রিয় সঠিক/ভুল নম্বর নয়। শিক্ষার্থী সঠিক উত্তরের সঙ্গে নিজের উত্তর মিলিয়ে প্রস্তুতি যাচাই করবে।

TXT ফরম্যাট: প্রতিটি প্রশ্নের মাঝে একটি খালি লাইন। প্রশ্ন: ও উত্তর: আবশ্যক। ব্যাখ্যা: ঐচ্ছিক। নমুনা sample-written-questions.txt ফাইলে আছে।

সেটআপ:
1) Supabase SQL Editor-এ migration-written-questions.sql একবার চালাও।
2) ZIP-এর index.html, style.css, app.js, config.js ফাইলগুলো GitHub repository-র পুরোনো ফাইলের ওপর overwrite করে আপলোড করো।
3) config.js-এ আগের Supabase URL ও anon/publishable key ঠিক আছে কি না দেখো। Secret/service_role key ব্যবহার করবে না।
4) GitHub Pages নতুন ফাইল deploy করলে সাইট refresh করো।

পুরোনো MCQ প্রশ্ন ডেটাবেসে থাকবে; নতুন পরীক্ষা লিখিত প্রশ্ন হিসেবে তৈরি হবে।
